## What the speaker explains

- **The definition, straight from Anthropic.** Tina quotes Anthropic's definition of MCP as "an open protocol that standardizes how your LLM applications connect to and work with your tools and data sources," and walks through it slowly because — as she admits — her first reaction was "Okay. What?"
- **A USB analogy to make it click.** She explains MCP by comparing it to a USB plug: it lets any device connect to any other device. Before a universal port standard existed, connecting a computer to a microphone or webcam meant dealing with different ports, special cords, adapters, and custom software for every pairing — which is exactly the fragmentation problem MCP removes for LLM applications.
- **MCP fundamentals, "under the hood."** She moves into the concepts and frameworks that govern MCP — the fundamentals you need in order to both *use* and *build* MCP servers — before doing anything hands-on.
- **The three server capabilities: Tools, Resources, and Prompt Templates.** A dedicated section (07:54) covers what an MCP server actually exposes.
- **The communication life cycle.** A section on how the pieces talk to each other over the course of a request (12:18), i.e. the sequence of interactions between the application and the MCP server.
- **Building your own MCP server two ways.** She demonstrates a no-code build first (15:47), then a code-based build (20:42), and points to her companion repo `github.com/hellotinah/MCP` for the code.
- **Built-in quizzes to check understanding.** Tina intersperses four quizzes throughout the video (07:34, 10:28, 15:41, 26:02) — her framing is that if you can answer them, "congratulations, you'll be educated on MCP."
- **Where her authority comes from.** She opens by noting she has taken a bunch of MCP courses, built MCP servers *and* clients for her team and for B2B clients, and teaches an MCP section in her AI agents bootcamp.
